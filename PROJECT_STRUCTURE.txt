WORKFLOW PATH THROUGH CODE
===========================

1. User fills IntakeForm.tsx
   └─> POST /api/incidents/ (incidents.py)
       └─> Creates IncidentState (incident.py)
           └─> Validates with decision_logic.py
               └─> Stores in incidents_db

2. User runs assessment in Investigation.tsx
   └─> POST /api/incidents/{id}/assess (incidents.py)
       └─> prompt_builder.py creates structured prompt
           └─> ai.py calls Claude API
               └─> Parses response
                   └─> decision_logic.py validates recommendations
                       └─> Returns assessment with risk level

3. User updates findings in Investigation.tsx
   └─> PUT /api/incidents/{id} (incidents.py)
       └─> Updates IncidentState
           └─> Validates with decision_logic.py

4. User gets containment in Containment.tsx
   └─> POST /api/incidents/{id}/containment (incidents.py)
       └─> prompt_builder.py creates containment prompt
           └─> ai.py calls Claude API
               └─> decision_logic.py validates actions
                   └─> Returns playbook + AI guidance

5. User exports summary in Summary.tsx
   └─> GET /api/incidents/{id}/export (incidents.py)
       └─> Generates final report
           └─> Returns IncidentSummaryExport


DATA FLOW
=========

User Input → Structured Form → Pydantic Validation → JSON Object
                                                           ↓
AI Response ← Claude API ← Controlled Prompt ← prompt_builder.py
     ↓
Parsed Sections → Validated Against Playbook → Combined with Playbook Steps
                                                         ↓
                                            Presented to Analyst
